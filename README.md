# Chatbot FDJ

A Streamlit chatbot that answers natural language questions about the FDJ Loto draw history.
It translates user questions into SQL queries, executes them against a local SQLite database,
and generates a grounded French answer using a language model via the OpenRouter API.

## Architecture

```
User question
    │
    ▼
prompt_builder  ──►  OpenRouterAdapter.generate_sql()
                              │
                              ▼
                       sql_validator  (whitelist + injection guard)
                              │
                              ▼
                       SQLite (lottery.db)
                              │
                              ▼
                     OpenRouterAdapter.generate_answer()
                              │
                              ▼
                       French answer → Streamlit UI
```

The project follows a **Port/Adapter** pattern:

- `domain/` — pure business logic, no external dependencies
  - `sql_validator.py` — security layer: blocks DML keywords, enforces table/column whitelists, detects multi-statement injection
  - `orchestrator.py` — pipeline coordinator
  - `prompt_builder.py` — builds the SQL generation prompt with schema and conversation history
  - `llm_port.py` — abstract interface (`LLMPort`) for language model adapters
  - `exceptions.py` — domain exception hierarchy
- `infrastructure/` — external adapters
  - `openrouter_adapter.py` — concrete `LLMPort` implementation backed by the OpenRouter API

## Requirements

- Python 3.13+
- [`uv`](https://docs.astral.sh/uv/) package manager
- An [OpenRouter](https://openrouter.ai/) API key

## Setup

```bash
# Clone and install dependencies
uv sync

# Configure environment variables
cp .env.example .env   # then fill in your OPENROUTER_API_KEY
```

`.env` file:

```dotenv
OPENROUTER_API_KEY=sk-or-...
OPENROUTER_MODEL=openrouter/auto   # optional, defaults to openrouter/auto
```

## Usage

### Streamlit web app (production)

```bash
uv run streamlit run app.py
```

Open `http://localhost:8501` in your browser.

### Interactive CLI (internal / demo)

Displays the generated SQL query and raw DB results — for development and demo use only.


## Security

SQL queries generated by the LLM go through a validation layer before execution:

- **Keyword blacklist**: `DROP`, `DELETE`, `INSERT`, `UPDATE`, `TRUNCATE`, `CREATE`, `ALTER` are rejected
- **Multi-statement guard**: queries containing `;` are rejected
- **Table whitelist**: only the `draws` table is allowed
- **CTE support**: `WITH … AS (…)` queries are allowed; virtual CTE names are excluded from the table whitelist check

## Database schema

Table: `draws`

| Column | Type | Description |
|---|---|---|
| `draw_year_id` | TEXT | Unique draw identifier (year + sequence number) |
| `draw_day` | TEXT | Day of the week (`LUNDI`, `MERCREDI`, `SAMEDI`) |
| `draw_date` | TEXT | Draw date (`YYYY-MM-DD`) |
| `ball_1` … `ball_5` | INTEGER | Five drawn numbers |
| `lucky_number` | INTEGER | Lucky number (numéro chance) |
